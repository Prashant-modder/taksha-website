MeritBits

A digital classroom credit and behaviour-tracking system for teachers, parents, and administrators.

Currently in closed testing on Google Play
Overview Features Screenshots Download Privacy Terms Delete Account
The idea

Discipline is not punishment.

"It's the currency of self-growth."

Every student begins with 5000 Merit. Teachers deduct points for infractions, parents follow the balance live, and every change is written to an unalterable history. It's not about shaming — it's about showing students that their choices have weight, and that they can see the shape of their own behaviour over time.

Built for

Three roles, one classroom.

◈

Class teachers

Create classes, add students individually or in bulk, deduct merit, reset the class, and post thoughts. Full control.

◆

Subject teachers

Join a class with a 6-character code. Deduct merit and post thoughts — nothing more, nothing less.

◇

Parents

Link a child by scanning their private QR. See merit, history, and receive notifications when things change.

The core flow

From first class to first deduction.

  1. 01
    Register as a Teacher or Parent. Verify email. Teachers wait for admin approval.
  2. 02
    Create a class (teacher) or join one with a code (subject teacher).
  3. 03
    Add students one by one or in bulk — name + roll number.
  4. 04
    Link a parent by scanning the student's QR code.
  5. 05
    Deduct merit — pick an infraction, confirm, points come off.
  6. 06
    Track — every change is saved. Parents see history and get notified.
  7. 07
    Reset the class each cycle. Negative balances carry over.
Merit rules

Simple, transparent, tamper-proof.

Starting value5000 for every new student
DeductionPoints are subtracted — no floor, merit can go negative
HistoryEvery deduction stores reason, points, and server timestamp
ResetClass teacher only. 5000 + any negative deficit carries over
ImmutabilityHistory entries cannot be edited once written
